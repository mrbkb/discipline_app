🔐 Politique de Confidentialité

Dernière mise à jour : 1er février 2026

En bref : Discipline respecte votre vie privée. Vos données restent privées, stockées localement sur votre appareil, avec sauvegarde cloud optionnelle. Nous ne vendons jamais vos données et ne diffusons aucune publicité.

1. Introduction

Bienvenue sur Discipline ("l'Application", "nous", "notre"). Cette politique de confidentialité explique comment nous collectons, utilisons, partageons et protégeons vos informations personnelles lorsque vous utilisez notre application mobile de gestion d'habitudes.

En utilisant Discipline, vous acceptez les pratiques décrites dans cette politique. Si vous n'acceptez pas cette politique, veuillez ne pas utiliser l'Application.

2. Données Collectées

2.1 Données que Vous Fournissez Directement

  • Surnom : Un pseudonyme choisi lors de l'onboarding (non obligé d'être votre vrai nom)
  • Habitudes : Titres et emojis des habitudes que vous créez
  • Dates de complétion : Jours où vous validez vos habitudes
  • Préférences :
    • Mode Hard activé/désactivé
    • Heures de rappel notifications
    • Notifications activées/désactivées

2.2 Données Collectées Automatiquement

  • Données d'usage :
    • Écrans visités (Firebase Analytics)
    • Actions effectuées (création habitude, validation, etc.)
    • Temps d'utilisation de l'app
  • Données techniques :
    • Modèle d'appareil
    • Système d'exploitation (Android version)
    • Version de l'application
    • Identifiant unique anonyme (Firebase UID)

2.3 Données que Nous NE Collectons PAS

  • ❌ Nom réel
  • ❌ Numéro de téléphone
  • ❌ Adresse email (sauf si vous créez un compte)
  • ❌ Localisation GPS
  • ❌ Contacts
  • ❌ Photos ou fichiers
  • ❌ Données bancaires (l'app est gratuite)

3. Comment Nous Utilisons Vos Données

3.1 Fonctionnement de l'Application

  • Afficher vos habitudes et statistiques
  • Calculer votre flamme de motivation
  • Envoyer des notifications de rappel
  • Sauvegarder vos progrès

3.2 Amélioration de l'Application

  • Analyser les fonctionnalités les plus utilisées
  • Détecter et corriger les bugs
  • Optimiser les performances
  • Comprendre comment améliorer l'UX

3.3 Utilisations Interdites

Nous n'utilisons JAMAIS vos données pour :

  • ❌ Vous envoyer de la publicité
  • ❌ Vendre à des tiers
  • ❌ Créer des profils marketing
  • ❌ Partager avec des réseaux sociaux

4. Stockage des Données

4.1 Stockage Local (Principal)

Toutes vos données sont stockées localement sur votre appareil dans une base de données chiffrée. Ces données ne quittent JAMAIS votre appareil sauf si vous activez la sauvegarde cloud.

4.2 Stockage Cloud (Optionnel)

Vos données sont sauvegardées dans :

  • Firebase Firestore (base de données Google Cloud)
  • Localisation : Serveurs Europe (GDPR compliant)
  • Chiffrement : Transport (TLS) + Repos (AES-256)
  • Accès : Uniquement vous + règles strictes Firestore

4.3 Durée de Conservation

  • Données locales : Jusqu'à désinstallation de l'app
  • Données cloud : Jusqu'à suppression de votre compte
  • Analytics : 14 mois (Firebase policy)

5. Partage des Données

5.1 Nous Partageons avec :

  • Firebase/Google : Pour sauvegarde cloud et analytics (obligatoire)
  • Personne d'autre

5.2 Cas de Partage Légal

Nous pouvons divulguer vos données si :

  • Requis par la loi (mandat judiciaire)
  • Protection de nos droits légaux
  • Prévention de fraude ou activité illégale

6. Vos Droits (RGPD)

Conformément au RGPD, vous avez le droit de :

6.1 Droit d'Accès

Demander une copie de toutes vos données

6.2 Droit de Rectification

Corriger vos données directement dans l'app (paramètres)

6.3 Droit à l'Effacement

Supprimer votre compte et toutes vos données :

  • Localement : Désinstaller l'app
  • Cloud : Nous contacter (email ci-dessous)

6.4 Droit de Portabilité

Exporter vos données dans un format standard (nous contacter)

6.5 Droit d'Opposition

Refuser l'analytics : Désactiver dans Paramètres > Analytics (si disponible)

7. Sécurité

7.1 Mesures de Protection

  • ✅ Chiffrement des données en transit (HTTPS/TLS)
  • ✅ Chiffrement des données au repos (AES-256)
  • ✅ Règles Firestore strictes (accès uniquement propriétaire)
  • ✅ Authentification Firebase sécurisée
  • ✅ Code obfusqué (ProGuard/R8)

7.2 Limites

Aucun système n'est 100% sécurisé. Nous faisons de notre mieux pour protéger vos données, mais ne pouvons garantir une sécurité absolue.

8. Enfants

Discipline est conçue pour les utilisateurs de 13 ans et plus. Nous ne collectons pas sciemment de données d'enfants de moins de 13 ans. Si vous êtes parent et découvrez que votre enfant nous a fourni des données, contactez-nous pour suppression.

9. Modifications de cette Politique

Nous pouvons modifier cette politique. Les changements seront publiés ici avec une nouvelle date "Dernière mise à jour". Les modifications importantes seront notifiées dans l'app.

Votre utilisation continue de l'app après modifications constitue votre acceptation.
